# Icon system

The interface uses Flaticon Uicons 4.0.0 in the Regular Rounded style. The stylesheet is loaded once in `index.html`, and every icon uses the `fi fi-rr-*` class pattern.

Keep icons paired with text when an action may be unfamiliar. Back, month navigation, and the assignment completion control may use an icon alone because they include an accessible label.

Main mappings:

- AI assistant: `fi-rr-robot`
- Calendar: `fi-rr-calendar`
- Sort: `fi-rr-sort-alt`
- Settings: `fi-rr-settings`
- Profile: `fi-rr-user`
- Classes: `fi-rr-graduation-cap`
- Lists: `fi-rr-list`
- Drafts: `fi-rr-file-edit`
- Time: `fi-rr-clock`
- Grade weight: `fi-rr-percentage`
- Priority: `fi-rr-flag`
- Delete: `fi-rr-trash`

Free Flaticon Uicons require attribution. The visible attribution link is in Settings and must remain while the free license is used.
